# Basic trading

Start here. Each of these is a complete strategy on its own.

| | |
|---|---|
| **[Grid](grid.md)** | Buy low, sell high, repeatedly, across a price range you set |
| **[Scheduled buying](dca.md)** | A fixed amount every interval, with a price floor |
| **[Conditional accumulation](accumulation.md)** | Buy only when the price is right, however long that takes |
| **[Take-profit ladder](take-profit.md)** | Sell parts of a position at rising targets |
| **[Limit trading](limit-trading.md)** | A standing offer, with an expiry and a fill policy |
| **[Swapping on demand](swap.md)** | A one-off trade, no strategy needed |
