# Counterparty strategies

Trading directly with someone you have agreed terms with, instead of through a public market.

| | |
|---|---|
| **[Passport-to-passport exchange](passport-swap.md)** | Two treasuries, one agreed trade, settled all-or-nothing |

Both sides receive what they agreed or nothing moves. See [trading directly with another treasury](../../../docs/advanced/passport-to-passport.md).
