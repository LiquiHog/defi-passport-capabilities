# Externally managed strategies

A passport enforces rules but forms no opinions. These are strategies where software supplies the opinion — reading the market, deciding what should change — while the passport keeps enforcing your limits.

| | |
|---|---|
| **[Volatility-controlled grid](volatility-controlled-grid.md)** | Widen the grid when choppy, tighten when calm |
| **[Trend-aware allocation](trend-aware-allocation.md)** | Shift the target mix as the trend changes |
| **[Dynamic rebalancing](dynamic-rebalancing.md)** | Rebalance when analysis says so, not on a fixed schedule |
| **[Risk controller](risk-controller.md)** | Cut exposure when your limits are breached, restore it when they are not |
| **[AI-managed allocation](ai-strategy-manager.md)** | Hand allocation to a model, inside guardrails you set |
| **[AI strategy planner](strategy-compiler.md)** | Turn a plain-language objective into funded rules |

A bad signal should cost you a bad trade, not your treasury. See [letting software run your strategy](../../../docs/advanced/external-controllers.md).
