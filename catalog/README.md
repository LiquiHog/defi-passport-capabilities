# The catalog

Three ways in, depending on how you're thinking about it.

**[Strategies](strategies/README.md)** — a single behavior you can fund and run. Start here if you know what you want the money to do: trade a range, buy weekly, lend the surplus.

**[Use cases](use-cases/README.md)** — someone else's situation, solved. Start here if you'd recognize your own problem in a description: a DAO paying contributors, an NFT project handling mint revenue, a merchant taking crypto.

**[Systems](systems/README.md)** — several strategies working as one treasury. Start here if you want the finished shape rather than the pieces.

Every page uses real amounts you can adapt. None of them require you to write code.
